# 院長の駄洒落 ポスターシリーズ（全30本 / 3枚）

石倉クリニック院長の駄洒落を、参考画像と同じ「番号＋見出し＋イラスト＋吹き出し」の
コマ割りに落とし込んだポスターです。1枚10コマ×3枚。

| 枚数 | タイトル | 出力ファイル |
|------|---------|-------------|
| Vol.1 | 院長の駄洒落10連発 | `dist/ishikura-dajare-10.png` |
| Vol.2 | 続・院長の駄洒落10連発 | `dist/ishikura-dajare-vol2.png` |
| Vol.3 | 続々・院長の駄洒落10連発 | `dist/ishikura-dajare-vol3.png` |
| 傑作選 | 院長の駄洒落 傑作選（全30本から上位10本） | `dist/ishikura-dajare-best.png` |

- サイズ：各 2400×3600px（1200×1800 の2倍解像度）
- SNS投稿・院内掲示・チラシのどれでも使える縦長比率（2:3）

## 傑作選（`poster4.html`）の選定基準

全30本を次の3点で採点し、3つとも高いものだけを収録しています。

1. **音の一致度** — 掛けている2語がどれだけ長く・正確に重なるか（1音ズレると格が落ちる）
2. **意味の二重成立** — 駄洒落として成立しつつ、文としても意味が通っているか
3. **意外性** — 遠い概念どうしが結びついているか（地名・人名・映画の名台詞など）

| 順位 | 駄洒落 | 評価ポイント |
|-----|--------|-------------|
| 1 | アーカンソー州では仕事辞めたらあかんそーだ | 州名がまるごと関西弁の一文になる。3点すべて最高評価 |
| 2 | オハイヨ州でおはよう皆の衆 | 「オハイオ／おはよう」に加え「州＝衆」まで回収する二段掛け |
| 3 | ピストルを撃てない動物、おら撃たん | なぞなぞ形式＋オランウータンとの完全一致 |
| 4 | シェーン、髪バック！ | 『シェーン』の名台詞を1音変えるだけで植毛の話になる |
| 5 | カタールで君の将来を語ーる | 「語る／カタール」の完全一致。文としても自然 |
| 6 | サルバトール・ザリガニ（ダリです！） | 一致する音が長い。「ダリです」で二段落ち |
| 7 | 上手い話にはノルマンディー | 「乗るまい」という警句を史実の地名で回収 |
| 8 | かなりやばいクリニック＝カナリヤクリニック | 一文をまるごと1語に圧縮。自虐が効いている |
| 9 | 助かりマスク | 「助かります」との完全一致。診療現場でそのまま使える |
| 10 | フォロワーの数がヘルナンデス | 「減るんです」が実在の人名と完全一致 |

**次点（あと一歩で殿堂入り）**：シンナーが体に悪いってしんなかった／願いが叶って叶姉妹／
ええジャマイカ、ほんじゃまいか／金融引き締め、顔も引き締めな／オーマイブッタ、どこぶった？

**落選の主な理由**：音が1〜2音ズレる（もうこりゴリラ、ロンドンでどんどん、カンパチでバチ当たる、
スペシャルハンバーグ）、駄洒落ではなくボケ（にんにくのガーリック味）、
掛けている語が弱い（ジーパン・ジジパン、包帯をマクドナルド）。

## 作り直し方

```sh
./fetch-fonts.sh          # Noto Sans JP を取得（初回のみ）
npm i playwright          # または既存の playwright を node_modules に symlink
node render.mjs                                          # Vol.1
node render.mjs poster2.html dist/ishikura-dajare-vol2.png  # Vol.2
node render.mjs poster3.html dist/ishikura-dajare-vol3.png  # Vol.3
node render.mjs poster4.html dist/ishikura-dajare-best.png  # 傑作選
```

### ファイル構成

| ファイル | 中身 |
|---------|------|
| `common.css` | 全ポスター共通のレイアウト・配色 |
| `doctor.js` | 院長イラストのSVGと、ポスター組み立て処理 `buildPoster()` |
| `scenes.js` | 全30コマぶんの背景イラスト（`S.<シーン名>`）。どのポスターからも使い回せる |
| `poster.html` 〜 `poster4.html` | 各号のコマ定義（`PANELS`）。傑作選は既存シーンの組み替えだけで作っている |

- 駄洒落の差し替え：各 `poster*.html` 末尾の `PANELS` 配列を編集（`t` が見出し、`b` が吹き出し）
- 院長イラスト：`doctor(pose, expr)` 関数。ポーズは `point / chin / phone / thumb / open`、
  表情は `smile / talk / wry / shock`
- 背景イラスト：`scenes.js` の `S.<シーン名>` に定義。新しいコマを足すときはここに追加する

## 画像生成AIで作画し直したい場合

参考画像のような描き込みのある絵にしたいときは、`ai-prompts.md` の各コマ用プロンプトを
画像生成AIに投げて、出来た絵を `poster.html` の背景（`S.*`）と差し替えてください。
