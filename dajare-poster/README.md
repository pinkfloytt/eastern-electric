## 作り直し方

```sh
./fetch-fonts.sh          # Noto Sans JP を取得（初回のみ）
npm i playwright          # または既存の playwright を node_modules に symlink
node render.mjs                                          # Vol.1
node render.mjs poster2.html dist/ishikura-dajare-vol2.png  # Vol.2
node render.mjs poster3.html dist/ishikura-dajare-vol3.png  # Vol.3
```

### ファイル構成

| ファイル | 中身 |
|---------|------|
| `common.css` | 全ポスター共通のレイアウト・配色 |
| `doctor.js` | 院長イラストのSVGと、ポスター組み立て処理 `buildPoster()` |
| `poster.html` / `poster2.html` / `poster3.html` | 各号の背景シーン（`S.*`）とコマ定義（`PANELS`） |

- 駄洒落の差し替え：各 `poster*.html` 末尾の `PANELS` 配列を編集（`t` が見出し、`b` が吹き出し）
- 院長イラスト：`doctor(pose, expr)` 関数。ポーズは `point / chin / phone / thumb / open`、
  表情は `smile / talk / wry / shock`
- 背景イラスト：`S.<シーン名>` に各コマのSVGを定義（各ポスターのHTML内）

## 画像生成AIで作画し直したい場合

参考画像のような描き込みのある絵にしたいときは、`ai-prompts.md` の各コマ用プロンプトを
画像生成AIに投げて、出来た絵を `poster.html` の背景（`S.*`）と差し替えてください。
